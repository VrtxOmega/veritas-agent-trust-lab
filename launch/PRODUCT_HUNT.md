# Product Hunt launch packet

**Name:** VERITAS Omega Agent Trust Lab

**Tagline:** Judge six AI-agent decisions before the answer key appears.

**Description:** A zero-signup blind calibration lab for the gap between a
plausible agent verdict and a recomputable, exact-bound, replay-resistant,
revocable assurance packet.

## First comment

Modern agent stacks are getting better at sandboxing, policy, identity, and
runtime controls. The boundary between “the evaluator said yes” and “this exact
action is still justified” remains hard to see.

This lab turns that boundary into six small attacks: forged result, parameter
swap, replay, correlated quorum, evidence deletion, and missing telemetry.

You judge a hidden three-clean/three-tampered mix before reveal. Labels stay
local unless you explicitly contribute a public GitHub issue.

The intentionally narrow claim: these synthetic fixtures deterministically
fail closed. This is not certification, an independent audit, or execution
authority. What should case seven be?
